# Pembagian Subnet (Subnetting)

Lakukan pembagian subnet (subnetting) untuk setiap jaringan berikut.

Tentukan untuk setiap subnet:

-   IP Network
-   Subnet Mask (prefix baru)
-   Host Pertama
-   Host Terakhir
-   Broadcast
-   Jumlah host per subnet

## 1. `192.168.1.0/24` dibagi menjadi 4 subnet

## 3. `17.8.0.0/16` dibagi menjadi 4 subnet

Mendekati 8 maka geser 3 bit = dari `2^3`.

  ----------------------------------------------------------------------------------
  IP Network   Sub Mask    Host awal    Host Akhir     Broadcast         Jumlah Host
  ------------ ----------- ------------ -------------- -------------- --------------
  17.8.0.0     /19         17.8.0.1     17.8.31.254    17.8.31.255             8.192

  17.8.32.0    /19         17.8.32.1    17.8.63.254    17.8.63.255             8.190

  17.8.64.0    /19         17.8.64.1    17.8.95.254    17.8.95.255             8.190

  17.8.96.0    /19         17.8.96.1    17.8.127.254   17.8.127.255            8.190

  17.8.128.0   /19         17.8.128.1   17.8.159.254   17.8.159.255            8.190

  17.8.160.0   /19         17.8.160.1   17.8.191.254   17.8.191.255            8.190

  17.8.192.0   /19         17.8.192.1   17.8.223.254   17.8.223.255            8.190

  17.8.224.0   /19         17.8.224.1   17.8.255.254   17.8.255.255            8.190
  ----------------------------------------------------------------------------------

> **Catatan:** Berdasarkan tabel pada dokumen, pembagian `/16` menjadi
> `/19` menghasilkan 8 subnet, bukan 4 subnet. Jumlah host usable per
> subnet adalah `2^(32-19) - 2 = 8.190`.
